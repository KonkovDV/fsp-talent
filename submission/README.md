# Материалы проекта ФСП Талант

**самостоятельный проект, лицензия MIT** · [репозиторий](https://github.com/KonkovDV/fsp-talent) · [документация](../docs/README.md)

Здесь лежат материалы, которые удобно открыть без чтения кода: презентация, видео, PDF документации и короткие путеводители. Источник правды — корневой [README](../README.md) и папка [`docs/`](../docs/README.md); файлы ниже на них ссылаются.

| Папка | Что внутри |
|---|---|
| [`01-repository/`](01-repository/README.md) | Стек, запуск одной командой, где лежат тесты |
| [`02-documentation/`](02-documentation/README.md) | PDF со всей документацией и список документов в `docs/` |
| [`03-presentation/`](03-presentation/README.md) | Презентация в PDF и PPTX |
| [`04-prototype/`](04-prototype/README.md) | Демо-входы по ролям, проверка за 2 минуты, локальный запуск |
| [`05-additional/`](05-additional/README.md) | Видео-демо, отчёты проверок, трассировка требований, спецификация API |

Копия PDF в `02-documentation/` совпадает с `docs/FSP_Talent_documentation.pdf` побайтно; оба файла собирает `make docs-pdf`.
