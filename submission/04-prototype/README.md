Модератора среди демо-входов нет специально. Разделы «Модерация» и «Методист» закрыты для опубликованных логинов: там видны имена кандидатов. Права выдаются с консоли сервера (`python -m app.services.staff`), вход на пульт модерации закрыт вторым фактором. Подробно — [USER_GUIDE.md](https://github.com/KonkovDV/fsp-talent/blob/main/docs/USER_GUIDE.md).

Стенд каждую ночь в 04:10 МСК возвращается в исходное состояние: у `jury1`…`jury10` снова пустой опрос и нет тестов, пароли прежние.

## Как поднять стенд локально

Нужны Docker 24+ с Compose 2.17+, 4 ГБ свободной памяти и свободные порты 80 и 8025.

```bash
git clone https://github.com/KonkovDV/fsp-talent.git
cd fsp-talent
make demo
```

Первый запуск занимает 5–10 минут. Сайт — http://localhost, Swagger UI — http://localhost/docs, письма с кодами — http://localhost:8025. Демо-входы те же. На Windows без make: `powershell -ExecutionPolicy Bypass -File scripts\start-local.ps1`. Подробности и частые проблемы — [INSTALL.md](https://github.com/KonkovDV/fsp-talent/blob/main/docs/INSTALL.md).
