# Согласие на распространение персональных данных

Шаблон для демонстрационного стенда. Перед запуском в эксплуатацию текст проверяет юрист оператора.

Отдельное согласие по ст. 10.1 Федерального закона № 152-ФЗ. Нужно только для **публичной страницы** кандидата и рейтинга. Анонимная карточка для работодателей этим согласием не регулируется.

**Какие данные станут доступны неограниченному кругу лиц:** имя для отображения, регион, специализация и грейд, результаты соревнований ФСП с проверяемыми удостоверениями, навыки.

**Что не публикуется никогда:** адрес электронной почты, телефон, Telegram, дата рождения, ФСП ID.

**Условия и запреты.** Запрещается передача (кроме предоставления доступа) неограниченному кругу лиц и любая иная обработка этих данных третьими лицами, кроме просмотра страницы.

**Срок и отзыв.** Согласие действует до отзыва. Отзыв в профиле выключает публичную страницу сразу. Несовершеннолетним публичная страница недоступна.
