# Согласие на распространение персональных данных

Шаблон для демонстрационного стенда. Перед запуском в эксплуатацию текст проверяет юрист оператора.

Отдельное согласие по ст. 10.1 Федерального закона № 152-ФЗ: оформляется отдельно от других согласий, отдельной отметкой. Нужно только для **публичной страницы** кандидата, рейтинга и поиска протоколов по ФСП ID. Анонимная карточка для работодателей этим согласием не регулируется.

**Какие данные станут доступны неограниченному кругу лиц:** имя для отображения, регион, специализация и грейд, результаты соревнований ФСП с проверяемыми удостоверениями, навыки.

**Что не публикуется никогда:** адрес электронной почты, телефон, Telegram, дата рождения, ФСП ID. Сам ФСП ID не показывается ни на публичной странице, ни в рейтинге.

**Поиск по ФСП ID.** Пока согласие действует, любой, кто уже знает ваш ФСП ID, может запросить по нему ваши протоколы ФСП: публичный адрес `/api/v1/public/telegram/achievements?fsp_id=…` и режим жюри «Протоколы». В ответе есть дисциплина, год, диапазон места и статус соревнования, но нет имени, контактов и грейда, и показываются только строки из реестра ФСП. Без действующего согласия, без публичной страницы и до 18 лет поиск по ФСП ID ничего не находит.

**Условия и запреты.** Запрещается передача (кроме предоставления доступа) неограниченному кругу лиц и любая иная обработка этих данных третьими лицами, кроме просмотра страницы.

**Срок и отзыв.** Согласие действует до отзыва. Отзыв в профиле сразу выключает публичную страницу, участие в рейтинге и поиск протоколов по ФСП ID. Несовершеннолетним публичная страница недоступна.
