# ФСП Талант

Обратный найм для трека ФСП на LCT-2026. Работодатель ищет категорию участников по протоколам и отправляет оффер с зарплатой. Имя и контакты открываются только после согласия кандидата.

## Запуск

```bash
cp .env.example .env
docker compose up -d --build
docker compose exec -u appuser backend python -m seed.generate_seed
```

Миграция выполняется при старте backend. Сайт: http://localhost (nginx). Если порты 8000 и 3000 заняты, в `docker-compose.yml` API опубликован на 8010, фронтенд на 3010.

Демо-вход:

| Кто | Логин | Пароль |
|-----|--------|--------|
| Участник | FSP001 | test |
| Участник | FSP002 | test |
| Работодатель | hr@yandex.demo | demo12345 |

Секрет мока ФСП для FSP001, FSP002 и FSP1000–FSP1149: `test`.

## Две оси профиля

Грейд не выводится из соревнований. Он берётся из самооценки или из стажа. Ось «подтверждено ФСП» считается отдельно, версия `v2.0.0`:

```
p = 1 - (place - 0.5) / N                 процентиль Хазена
q = W(разряд ЕВСК) * p                    качество результата
w = 2^(-месяцы / 18) / sqrt(размер команды)
μ = (Σ w q + K μ0) / (Σ w + K)            K=2, μ0=0.30
σ = sqrt(0.04 / (Σ w + K))
ранжирование по LCB = μ - σ
```

Командный результат уменьшает вес доказательства и расширяет σ, а не снижает уровень. Разряд-эквивалент — упрощённая лестница ЕВСК; МС и КМС требуют не меньше 6 участников.

## Поиск

Жёсткие фильтры в SQL: профиль открыт, несовершеннолетний только с согласием, роль, грейд, дисциплина, минимальный разряд. Дальше лексический ранг (`ts_rank` + триграммы) и опционально векторный поиск. Слияние — RRF с K=60. Итоговый порядок: покрытие навыков, RRF, лучший LCB. Карточка анонимна: статус соревнования, год и корзина процентиля, без названия события и точного места.

Плотные эмбеддинги выключены (`EMBEDDINGS_MODE=off`), пока не подключён `sentence-transformers`. Разбор резюме работает правилами; GigaChat добавляет навыки только если цитата дословно есть в тексте и задан `GIGACHAT_CREDENTIALS`.

## Удостоверения

W3C VC Data Model 2.0, Data Integrity `eddsa-jcs-2022`. Издатель — платформа, не ФСП: она подтверждает, что результат получен из системы ФСП. Проверка: `GET /api/v1/public/issuer` и `POST /api/v1/public/credentials/verify`.

## Правовые границы прототипа

Контакты видны только после принятия оффера; событие пишется в `consent_logs`, просмотр — в `access_logs`. Именная страница и лидерборд недоступны несовершеннолетним. ИИ только предлагает навыки и разбирает запрос, решение остаётся за человеком.
