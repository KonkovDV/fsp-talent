# 0003. Ось ФСП — нижняя граница, которая только поднимает

**Контекст.** ТЗ 2.1 и ответ постановщика: результаты ФСП — дополнительное доказательство, участие без результата не должно вредить, все соревнования равноценны. Простое среднее по событиям наказывает того, кто участвовал часто.

**Решение.** Балл оси — нижняя граница (μ − σ) по лучшему подмножеству не более пяти событий с результатом, пустое подмножество остаётся в переборе (`backend/app/services/scoring/engine.py`). Участие без результата считается в профиле и в сумму не входит; командный результат расширяет σ, а не снижает уровень. В подборке ось только поднимает доказательства над тестом: `T + 0,5·max(0, F − T)` (`FSP_LIFT = "boost"`, `backend/app/services/matching.py`).

**Альтернативы.** Взвешенное среднее по всем событиям не подошло: участие без места тянет его вниз. Ранг соревнования как вес («чемпионат выше хакатона») постановщик не рекомендовал. Если сделать ось отдельным равноправным фактором, она может опустить кандидата с сильным тестом.

**Последствия.** Добавление события никогда не снижает балл, отсутствие истории — нижняя точка, а не штраф ([подъём оси ФСП](../VALIDATION_MATCHING.md#подъём-оси-фсп)). Цена на трёх публичных зёрнах — nDCG@10 0,650 → 0,649. Константы — экспертные априоры: любое изменение поднимает версию движка.
