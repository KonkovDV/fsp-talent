# 0005. Российские облачные модели без GPU, правила как основа

**Контекст.** Машина жюри без видеокарты, данные кандидатов — персональные. Модель полезна для разбора резюме и черновиков заданий, но решение не должно от неё зависеть.

**Решение.** Разбор резюме сначала правилами: каждый навык с дословной цитатой (`backend/app/services/ai/assistant.py`). Модель только дополняет; при ошибке вызова возвращается результат правил. Провайдеры — закрытый список из четырёх российских облаков с зашитыми адресами: GigaChat, YandexGPT, Cloud.ru, MWS GPT (`backend/app/services/ai/providers.py`). Перед вызовом текст проходит `for_model`: имя, почта и телефон до провайдера не доходят. Модель не ранжирует кандидатов: балл подбора — разложимая сумма.

**Альтернативы.** Локальная модель на GPU — требование к железу, которого у жюри нет. Зарубежные API — передача данных за рубеж. Ранжирование моделью — результат нельзя объяснить кандидату и работодателю.

**Последствия.** С `AI_ENABLED=false` или без ключа продукт работает целиком ([VALIDATION_NLP.md](../VALIDATION_NLP.md) — точность разбора правилами). Провайдера переключает сотрудник на столе модерации без перезапуска; ключ хранится зашифрованным и через API не возвращается.
