# 0008. Публичные страницы без ячеек меньше пяти человек

**Контекст.** Витрина банка («специализация × грейд»), публичный рейтинг категории и статистика показывают агрегаты без входа. Ячейка из одного-двух человек вместе с открытыми фактами выдаёт конкретного кандидата.

**Решение.** Ячейка или категория, где меньше пяти человек, скрывается (`BANK_MIN = 5`, `backend/app/services/search/pipeline.py`; публичные адреса API в `backend/app/api/v1/public.py`). Рейтинг категории показывает места и оценку теста без имён. Публичный профиль по ФСП ID — только у совершеннолетнего с согласием на распространение (ст. 10.1 152-ФЗ).

**Альтернативы.** Показывать всё — риск деанонимизации в малых категориях. Добавлять шум к счётчикам — числа перестают сходиться с выдачей, их трудно проверить. Закрыть агрегаты целиком — работодатель не видит, есть ли кандидаты до регистрации.

**Последствия.** На маленьком стенде часть ячеек пустая, это нормально. Тот же порог используется в проверке справедливости выдачи: группы меньше пяти человек не сравниваются.
