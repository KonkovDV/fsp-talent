# 0006. Один сервис FastAPI вместо микросервисов

**Контекст.** Команда маленькая, стенд должен подниматься одной командой на машине жюри. Тест, подбор и согласия делят одни таблицы и одну транзакцию.

**Решение.** Один процесс FastAPI с модулями по доменам: маршруты в `backend/app/api/v1/`, логика в `backend/app/services/`, модели в `backend/app/models/`. Отдельно вынесено только то, что требует изоляции: песочница запуска кода (`sandbox/`), а фоновый воркер и планировщик — тот же образ backend с другой командой. PostgreSQL 16 с pgvector и Redis 7 — общие.

**Альтернативы.** Микросервисы по доменам — сетевые вызовы и согласованность между базами без выигрыша на нагрузке хакатона. Serverless — холодный старт и нет общей транзакции для согласия и выдачи контактов.

**Последствия.** Согласие, выдача контактов и запись в журнал доступа идут в одной транзакции. Нагрузку стенда проверяет [LOAD_TEST.md](../LOAD_TEST.md). Граница модулей держится соглашением, а не сетью, поэтому её стережёт ревью.
