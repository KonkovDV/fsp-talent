ПРОБЛЕМА И ОТВЕТ

Резюме обещает, тест подтверждает

Проблема. Работодатель видит заявленный грейд и список технологий. Сортировка по резюме ставит в первую десятку 28 % людей с завышенным грейдом.
Ответ. Грейд даёт только адаптивный тест специализации. Результаты ФСП — отдельная подтверждённая ось, без неё человек не теряет место.
Механика. Работодатель описывает потребность, получает подборку с разбором каждого места и приглашает первым, сразу с вилкой.

ПУТЬ КАНДИДАТА

Опрос, пробный тест, категория

  • Кандидат выбирает специализацию и грейд, стаж только подсказывает.
  • Пробный тест: 15 заданий за 5 минут, нейтральный итог с вероятностью уровня.
  • Полный тест подтверждает грейд. Не сдали — ступень ниже доступна сразу.
МЕХАНИКА КОНТАКТА

Приглашение с вилкой, контакты после согласия

  • Карточки анонимны: имя и контакты открываются, только когда кандидат принял приглашение.
  • Не больше 50 приглашений в день от компании, срок ответа 14 дней.
  • После отказа та же компания ждёт 30 дней. Кандидат может закрыть контакты для одной компании.
