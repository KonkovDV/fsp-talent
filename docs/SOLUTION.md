# ФСП Талант: сопроводительное описание решения

Документ закрывает раздел 3.4 технического задания спецтрека. Цифры валидации — из прогонов кода, не из оценок на глаз.

## Функциональная и компонентная архитектура

Монолит с тремя слоями. Frontend — React, Vite, TypeScript. Backend — FastAPI, SQLAlchemy, Alembic. Хранение — PostgreSQL 16 (pgvector, pg_trgm) и Redis для лимитов. Контейнеры: `docker-compose.yml`. Публично снаружи nginx на порту 80; API и база на localhost.

Роли разделены токеном: кандидат не вызывает поиск и приглашения, работодатель не меняет чужой профиль. Контакты отдаёт отдельный эндпоинт и только после принятия приглашения или своего отклика. Событие пишется в журнал доступа.

## Механика тестирования

Единый банк вопросов не используется: он утечёт. Нейросеть не генерирует задание на каждого кандидата: сложность была бы несравнима.

Задание собирает параметрическое семейство. Ответ вычисляется кодом. Юнит-тест перезапускает фрагмент в Python, Node.js, Go, Java или SQLite и сверяет ключ. Концептуальных вопросов не больше 30 %.

Сессия адаптивная (3PL, апостериор на сетке). Следующее задание выбирается по информации у порога заявленного грейда. Остановка при 8–20 заданиях, когда вероятность уровня уже решена. Грейд не понижается. Повышение не чаще чем раз в 90 дней. Пересдача того же уровня — через 7 дней.

Описание вакансии меняет доли тем: названные навыки подтягивают свои семейства, остальное остаётся планом специализации (`app/services/vacancy_exam.py`). Работодатель нажимает «Какой тест получится» и видит доли и три примера без ключа. Кандидат может пройти полный тест по вакансии или одно короткое задание. Короткое задание не меняет грейд и отмечается на анонимной карточке как свежая практика. Идея взята у «Контура талантов» (задание из требований роли и добровольная практика); исполнение — наши семейства, без чужого кода и без запуска присланного кандидатом кода.

Утечка ловится по дрейфу решаемости. Ключ с z ≥ 3,5 уходит в карантин и больше не выдаётся.

Процедура и цифры: [VALIDATION_ASSESSMENT.md](VALIDATION_ASSESSMENT.md). Если способность дальше 0,5 от границы грейда, тест прав примерно в 88 % случаев. Утечка у 30 % кандидатов поднимает долю ложно сдавших с 10 % до 19 %; карантин возвращает её к 12,7 %.

## Механика подбора и категоризация

Категория — специализация из опроса и грейд. Грейд подтверждает тест по этой специализации. Соревнования в грейд не переводятся: это отдельная ось, скоринг `v2.0.0` (процентиль Хазена, лестница ЕВСК, сжатие к среднему, ранжирование по нижней границе, командный вес `1/√m`).

Работодатель описывает потребность. Подборка объясняется факторами. Соответствие потребности (навыки, грейд, специализация) решает, попадает ли человек в список. Внутри одной сотой этого соответствия выше тот, у кого сильнее тест и протокол ФСП. Нет истории ФСП — ось выбрасывается и не штрафует. Заявленный навык весит 0,55 от навыка, который подтвердил тест.

Цифры: [VALIDATION_MATCHING.md](VALIDATION_MATCHING.md). На двух синтетических наборах скор выше базовой линии по ключевым словам на 0,040 и 0,051 nDCG@10.

## Интеграция с реестром ФСП

API реестра в хакатоне нет. Адаптер `MockFSPAdapter` отдаёт синтетические протоколы; `RealFSPAdapter` ждёт спецификацию. ФСП ID привязывается в профиле после регистрации по почте и не обязателен. Издатель удостоверения — платформа, не Федерация: она подтверждает, что результат получен из системы ФСП. Проверка подписи: `GET /api/v1/public/issuer` и `POST /api/v1/public/credentials/verify`.

## API

Спецификация: `http://localhost:8010/docs` (Swagger включён независимо от режима отладки). Ошибки одного формата с машинным кодом: [API_ERRORS.md](API_ERRORS.md).

## Библиотеки

Версии фиксирует `backend/pyproject.toml` и `frontend/package-lock.json`. Основные: FastAPI, SQLAlchemy 2, Alembic, Pydantic v2, bcrypt, python-jose, React 18, Vite 6, Tailwind. Эмбеддинги выключены (`EMBEDDINGS_MODE=off`), пока не подключена модель.

## Запуск

```bash
cp .env.example .env
docker compose up -d --build
docker compose exec -u appuser backend python -m seed.generate_seed
```

Сайт: http://localhost. Письма с кодами: http://localhost:8025. Демо-пароль `demo12345`: `fsp001@demo.talent`, `nofsp@demo.talent`, `hr@sibcode.demo`.

Проверки: `cd backend && pytest tests/unit` и `cd frontend && npm run type-check && npm run build`. CI делает то же плюс миграции и дымовой тест.
