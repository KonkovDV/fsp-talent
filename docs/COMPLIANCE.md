# Соответствие требованиям: персональные данные, честность решений, права

Этот раздел описывает, как «ФСП Талант» выполняет требования 152-ФЗ, Трудового кодекса и гражданского законодательства. Каждый пункт подтверждается кодом или текстом документа в репозитории.

## Персональные данные (152-ФЗ)

| Требование | Как сделано | Где проверить |
|---|---|---|
| Отдельное согласие на обработку (ст. 9 ч. 1, ред. 156-ФЗ) | Согласие — самостоятельный документ, не входит в пользовательское соглашение | `backend/app/legal/docs/pd_candidate.md`, `pd_employer.md` |
| Отдельное согласие на распространение (ст. 10.1) | Публичная страница, рейтинг и поиск протоколов по ФСП ID (`/public/telegram/achievements`) доступны только с этим согласием. Текст v1.1 прямо называет поиск по ФСП ID, отзыв выключает все три | `pd_distribution.md`, `api/v1/candidates.py`, `api/v1/public.py` (`_public_filter`) |
| Политика обработки ПДн (ст. 18.1 ч. 2) | Опубликована на `/privacy`, в «Документах и согласиях» и в подвале, ссылка есть в форме регистрации. Это не согласие: принять или отозвать её нельзя. Оператор демо-стенда — команда-участник ЛЦТ-2026, в промышленном контуре — ФСП или владелец платформы | `backend/app/legal/docs/privacy_policy.md`, `PrivacyPage.tsx` |
| Демо-стенд вне РФ | При `DEMO_MODE` на `/register`, в текстах согласий, на `/legal` и `/privacy` плашка: сервер вне России, реальные данные не вводить. В промышленном контуре её нет | `components/DemoStandNotice.tsx` |
| Доказуемость редакции согласия | Хранятся вид, версия и SHA-256 точного текста | `backend/app/legal/__init__.py`, `services/identity.py` |
| Минимизация раскрытия | Публичный профиль никогда не показывает e-mail, телефон, Telegram, дату рождения и ФСП ID; работодатель видит анонимную карточку, контакты — только после согласия кандидата | `services/privacy.py` |
| Несовершеннолетние 15–17 лет (ст. 9 ч. 6) | Карточка скрыта до согласия законного представителя; отдельная страница для представителя | `services/guardian.py`, `GuardianPage` |
| Права субъекта (ст. 14, 21) | Отзыв любого согласия в профиле с объяснением последствий, удаление аккаунта, экспорт своих данных, журнал просмотров контактов | `ConsentsPanel.tsx`, `services/account_export.py` |
| Автоматизированные решения (ст. 16) | Категория справочная и объяснимая, решение о найме принимает человек; результат теста можно оспорить, тест — пересдать | `pd_candidate.md` «Решения», `candidate/Assessment.tsx` |
| Локализация (ст. 18 ч. 5) | При эксплуатации данные граждан РФ хранятся в базах на территории РФ: решение разворачивается на сервере оператора. Демонстрационный стенд эту локализацию не обещает. Поставщики языковых моделей (LLM) в коде — только российские облака | `pd_candidate.md`, `services/ai/providers.py` |
| Инциденты (ст. 21 ч. 3.1) | Порядок уведомления Роскомнадзора за 24/72 часа отражён в согласиях | `pd_candidate.md` |
| Защита данных (ст. 19) | Шифрование чувствительных полей, пароли — Argon2id, токен обновления сессии в cookie, недоступной скриптам страницы (HttpOnly), защита от подделки запросов (CSRF) | `services/field_cipher.py`, `core/security.py` |
| Cookie и отслеживание | Сторонней аналитики и cookie для отслеживания нет, поэтому баннер cookie не требуется | `frontend/package.json` |
| ИИ-помощник | Модель получает резюме без имени и контактов, предлагает навыки, но ничего не решает: каждый навык подтверждает кандидат | `services/ai/assistant.py` |

## Недискриминация (ТК РФ ст. 3, 64)

Пол, возраст и национальность в подборе не используются. Грейд ставит только тест и не зависит от статуса соревнования: все соревнования ФСП равны.
