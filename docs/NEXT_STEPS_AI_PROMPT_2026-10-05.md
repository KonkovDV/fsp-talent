### A.5. Решения: что берём и как сделать лучше конкурента

| Идея (у кого есть) | Наш вариант |
|---|---|
| Письма о приглашении и ответе (S) | Письмо **плюс** уведомление в кабинете (таблица `notifications`, бейдж в шапке). Тексты без ПДн другой стороны |
| Превью теста под потребность (S) | Блок «Как проверим кандидатов» на странице потребности: доли тем из blueprint, 2 примера заданий, язык кода. Это закрывает R-06 ТЗ («как тест зависит от вакансии») |
| Перцентиль в категории (S) | «Лучше 82 % кандидатов категории Backend × Middle» в разборе скора |
| Грейд «Стажёр» (S) | intern как пятый грейд: порог θ, уровни L1, трек для студентов и школьников ФСП |
| 6 языков кода (S) | Расширить мультиязычность на все семейства с кодом, добавить Kotlin и C#. Проверка компиляторами в CI |
| 12 специализаций (S) | Добавить QA, системного аналитика, data engineer. Оставить embedded и БАС: они связаны с дисциплинами ФСП |
| Сравнение до 3 кандидатов (Z) | Таблица-протокол: факторы скора построчно, пробелы навыков |
| Паспорт навыков (Z) | Навык → источник (тест, ФСП, заявлен) → дата → доверие. Источник уже есть в модели навыков |
| PDF-резюме (Z, I) | Загрузка PDF через pypdf → существующий разбор. PDF-профиль через WeasyPrint с нашими шрифтами |
| ФСП ID по OIDC (I) | Не поднимать Keycloak. Нужны ADR и OIDC-совместимый интерфейс провайдера (`FspIdProvider`): mock сейчас, OIDC в проде. В UI убрать поле пароля от ФСП, сделать имитацию редиректа |
| Уровень мероприятия по ЕКП (ekp-parser) | Поле `ekp_number` и уровень в модели события, бейдж «внесено в ЕКП Минспорта» в доказательствах. Данные чужого парсера не брать: в моке — номера-заглушки, источник — первичный ЕКП |
| Симуляция теста в CI (S) | `python -m app.validation.assessment --n 300` с порогами: ложное прохождение не больше 12 %, точность не меньше 72 % |
| Удаление аккаунта (S) | `DELETE /me` и celery-задача очистки через 30 дней после отзыва `pd_candidate`. Закрывает D2 |
| Пакет для жюри (Z) | Сценарий демо на 5 минут, презентация на 10 слайдов, видео на 3 минуты, URL стенда в первой строке README |
